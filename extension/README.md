# unfetch 浏览器扩展

将 Chrome / Edge 的下载转发到 unfetch 桌面客户端。

## 安装（开发者模式）

1. 浏览器打开 `chrome://extensions/`（Edge 打开 `edge://extensions/`）
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」
4. 选择 `D:\code\unfetch\extension\` 目录

## 工作原理

- 监听 `chrome.downloads.onCreated` 事件
- 取消浏览器原生下载，把 URL POST 到 daemon `http://127.0.0.1:19543/tasks`
- 显示桌面通知

## 设置

点击工具栏图标：

- **启用接管**：总开关，关闭后所有下载走浏览器原生
- **最小文件大小**：小于该值的下载让浏览器处理（默认 0 不限）
- **忽略后缀**：这些后缀的文件不接管（默认 html/htm/txt/css/js/json）
- **白名单域名**：这些域名的下载不接管（如内网、办公系统等）

## 右键菜单

- 链接上右键 → 「用 unfetch 下载链接」
- 视频页面右键 → 「用 unfetch 下载此页面（视频）」会用 yt-dlp 解析

## 故障排查

| 现象 | 原因 |
|------|------|
| 工具栏图标红色感叹号 | daemon 没启动，打开 unfetch 桌面客户端 |
| 下载不被接管 | 检查总开关是否打开、最小文件大小、域名/后缀白名单 |
| 下载被两次保存 | 极少数情况下浏览器抢先一步，刷新页面重新触发 |
